# The Hidden Zones of Stagnation (HZOS) Assessment

An executive-level diagnostic instrument designed to identify operational bottlenecks and developmental constraints across 13 core capacity zones.

## Overview

The Hidden Zones of Stagnation (HZOS) diagnostic framework helps leaders and organizations uncover why high activity doesn't always translate into forward momentum. Through 65 targeted diagnostic items, evidence verification audits, and qualitative interview prompts, HZOS isolates specific restriction tiers.

## Core Features

- **13 Diagnostic Zones**: Vision, Identity, Conviction, Knowledge, Competency, Execution, Systems, Relationships, Resources, Environment, Energy, Feedback, and Spiritual Alignment.
- **Focused Step Flow**: Sequential question flow with sub-step progress tracking, custom balanced selectors, and smooth animations.
- **Evidence Verification Protocol**: Verifiable documentation paired with a 5-tier evidence strength rating (E0 to E4) and real-time diagnostic pill feedback.
- **Interactive Stagnation Radar**: Visual polar polygon mapping developmental restriction tiers.
- **Constraint Discovery Interview**: Qualitative root-cause inquiry prompts to diagnose underlying factors.
- **Word Document Export**: Downloadable executive diagnostic reports and interview workbooks.
- **Responsive & Dark Mode**: Full cross-device support with adaptive dark mode styling.
